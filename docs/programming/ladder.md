# Practice ladder

Rungs 1–4 are the pre-kickoff bar for everyone touching robot code. All of them work in the [simulator](https://vrobotsim.com/) if you don't have hub access.

- [ ] **1.** OpMode that prints a counter to telemetry — *toolchain + deploy works*
- [ ] **2.** One motor controlled by one stick — *hardwareMap, gamepad, the loop*
- [ ] **3.** Tank-drive TeleOp — *a driveable robot*
- [ ] **4.** Mecanum TeleOp with deadband, shaping, slow mode — *real driver control*
- [ ] **5.** Mechanism with presets and software limits — *RUN_TO_POSITION + safety*
- [ ] **6.** Encoder auto: out, 90° IMU turn, back — 3× repeatable — *autonomous fundamentals*
- [ ] **7.** Multi-step action as a state machine (no sleep) — *season-proof structure*
- [ ] **8.** Capstone: full TeleOp for last year's robot, from a blank file — *all of it*
