# Resources

Everything worth bookmarking, and *when* to reach for it.

## Programming

- **[gm0.org](https://gm0.org)** (Game Manual 0) — the community-written FTC bible; its software section is the best single resource in FTC. When our pages are too thin, go there.
- **[ftc-docs.firstinspires.org](https://ftc-docs.firstinspires.org)** — official docs: hub setup, configuration, SDK features.
- **The SDK's own samples** — in the FtcRobotController project, the external samples folder has a working example for nearly every device. Copy, rename, learn.
- **[CTRL ALT FTC](https://www.ctrlaltftc.com)** — when you're ready for PID and real control theory.
- **Learn Road Runner / Pedro Pathing docs** — tuning walkthroughs for path following, whichever we run. **[FILL IN: which one we use + our tuning doc]**
- **[Virtual Robot Simulator](https://vrobotsim.com/)** — write and drive FTC code with no hardware. Rungs 1–4 of the [programming ladder](../programming/ladder.md) work in it.

## CAD

- **Autodesk's own self-paced Fusion tutorials** — solid for tool-by-tool basics.
- **"Learn Fusion 360 in 30 Days" (Product Design Online, YouTube)** — the classic free course; days 1–10 map roughly to Sessions 1–3.
- **Vendor CAD** — goBILDA and REV product pages (STEP files), McMaster-Carr via Fusion's Insert menu, GrabCAD for community models.
- **gm0.org** — Game Manual 0's design pages, for the *why* behind mechanism and drivetrain choices.
