## Done-by-kickoff checklist

The game drops in early September. By then:

- [ ] Everyone touching CAD has finished the [CAD practice ladder](cad/ladder.md)
- [ ] Everyone touching code has finished rungs 1–4 of the [programming ladder](programming/ladder.md)
- [ ] Everyone has made at least [one PR to this site](contributing/first-pr.md)
