# Session 0 — Setup

Do this before the first workshop.

1. Get Fusion 360 free through Autodesk's education program: **autodesk.com/education**. Verify with your school email or enrollment proof. Licenses renew yearly — set a reminder.
2. Install Fusion and sign in with that account.
3. Get added to the team's shared Fusion project: **[FILL IN: Fusion Team hub link + who sends invites]**
4. Set default units to millimeters (Preferences → Default Units → Design). Nearly all FTC hardware is metric. **[FILL IN: note if the team uses inches for anything]**
5. Use a real mouse. **Scroll** = zoom, **middle-drag** = pan, ++shift++ + **middle-drag** = orbit. This alone will 3x your speed versus a trackpad.

## The 60-second mental model

Fusion is **parametric**: you don't sculpt a shape, you record a sequence of steps — the **timeline** at the bottom of the screen. Edit an early step and everything after it updates. Almost everything follows one rhythm: draw a 2D **sketch**, then turn it into 3D with a **feature** (extrude, revolve, etc.).

!!! warning "Rule #1 — start today, understand it in Session 3"

    Before you model anything: right-click the top of the browser → **New Component**, and activate it. Modeling loose bodies at the top level is the #1 habit that wrecks robot assemblies later.

    Why it matters is explained in [Session 3](3-assemblies.md). Do it now anyway.
